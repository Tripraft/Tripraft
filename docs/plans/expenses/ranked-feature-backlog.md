# Ranked expense management feature backlog

Updated: October 25, 2026.

This is the combined ranking of all 45 general ideas and all 15 advanced concepts, from highest to lowest priority. Ranking weighs daily usefulness, personal and travel relevance, delivery effort, dependencies, and differentiation. It is a proposed backlog, not an implementation status report or release schedule.

**Users:** Personal = individual expense management; Travel = group trips and shared expenses; Both = both audiences.

**Original references:** G01-G45 refer to the earlier general list; A01-A15 refer to the earlier advanced list. The Rank column below is the authoritative combined ordering. Advanced entries have more detail in [Advanced concepts](advanced-concepts.md).

## Delivery considerations

Start with ranks 1-6 to reduce manual effort and improve planning. User research can change the order before development begins. The advanced concepts should build on accurate transactions, explicit participation, saved group rules, booking terms, and clear separation between estimates and actual money.

Some entries intentionally address related problems at different depths. For example, a refund linked to its original expense is a foundation; a refund and deposit timeline adds the timing of cash movements. Dispute tracking records an issue; a correction proposal calculates the precise balance changes before approval. Preserve these relationships when breaking work into releases.
