# Extra document references

`blueprint-review/` preserves the previously extracted enterprise blueprint text
and its 23 rendered page images, relocated from `extra/blueprint-review/`.
The document-processing libraries were left at their existing tools path.
These local reference artifacts are ignored by Git and Docker; only this index is
published. They are not source code or database input.

Earlier source-code recovery archives, path mappings, environments, dependency
caches and tools remain in the root `extra/` tree because they have different
purposes and existing path references. See [project structure](../project-structure.md).
